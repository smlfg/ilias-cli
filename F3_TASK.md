# Task
Implement **F2 `ilias courses`** and **F3 `ilias ls <kurs>`** for the **Moodle** backend of this ILIAS/Moodle CLI (see ANFORDERUNGEN.md §F2/F3, INTERFACE.md, MOODLE.md). Login/status/logout for Moodle already exist and work live against HS Mannheim (`--instance hs-mannheim`); build on them, do not rewrite them.

## Commands
1. `ilias courses [--instance X] [--json]` lists the logged-in user's Moodle courses.
   - Flow: stored token → `core_webservice_get_site_info` (gets `userid`) → `core_enrol_get_users_courses` with `userid`.
   - Fields per course: `id`, `fullname`, `shortname`, `category` (int id, null if missing), `semester` (string or null), `visible` (bool), `startdate`/`enddate` (ISO 8601 Europe/Berlin or null when 0/missing), `url` (`{base}/course/view.php?id=<id>`).
   - `semester`: derive from `startdate` in Europe/Berlin: months Apr–Sep give `"SoSe YYYY"`, Oct–Dec give `"WiSe YYYY/YY+1"`, Jan–Mar give `"WiSe YYYY-1/YY"` (e.g. 2026-10-01 gives `"WiSe 2026/27"`, 2027-02-01 gives `"WiSe 2026/27"`). startdate 0/missing gives null.
   - Human output: a rich Table (ID, Kurzname, Name, Semester), sorted by semester (newest first, null last), then fullname. `--json`: exactly one JSON object on stdout: `{"instance", "lms", "count", "courses": [...], "timestamp"}`.
2. `ilias ls <kurs> [--instance X] [--depth N] [--json]` shows the content of one course as a tree.
   - `<kurs>` is either a numeric course id, or a case-insensitive substring of fullname/shortname. Exactly one match: use it. An exact (case-insensitive) shortname or fullname match wins over substring matches. No match: clear error (exit 1, error_code `course_not_found`). Several matches: clear error listing the candidates (id, shortname, fullname) in the message and, with `--json`, as `"candidates": [...]` in the error object (exit 1, error_code `course_ambiguous`).
   - Flow: resolve course (via the courses list), then `core_course_get_contents` with `courseid`.
   - Tree: course → sections → modules → files. Folder modules (`modname == "folder"`) contain files whose `filepath` (e.g. `/`, `/Blatt 1/`, `/Blatt 1/Lösungen/`) must become nested sub-folder nodes. Resource modules show their file(s). `url` modules show the target URL. Other modules (assign, forum, quiz, page, label, choice, lti, …) are leaf nodes with a type label.
   - `--depth N`: 1 = sections only, 2 = + modules, 3 = + files/first folder level, each further level = one more sub-folder level. Default: unlimited. N < 1 → usage error (exit 2 is typer's default for usage errors; that is fine).
   - Visibility: modules/sections with `uservisible == false` are still listed but marked (e.g. `[gesperrt]` plus `availabilityinfo` stripped of HTML if present); `visible == 0` is marked `[verborgen]`. `label` modules: show a short plain-text name (strip HTML, max 60 chars). Empty sections (no modules, no name or default name) may be skipped in the human view but must be present in JSON.
   - Human output: a rich `Tree` with type icons/labels (e.g. 📁 Ordner, 📄 Datei with size in KB/MB, 📝 Aufgabe, 💬 Forum, 🔗 Link, ❓ Test, 📃 Seite) — any consistent, readable scheme. Escape rich markup in all server-provided strings.
   - `--json`: one JSON object: `{"instance", "lms", "course": {id, fullname, shortname}, "depth": N|null, "sections": [{"id", "number", "name", "visible", "uservisible", "modules": [{"id", "name", "modname", "url", "visible", "uservisible", "availability", "children": [ nested nodes: {"type": "folder", "name", "path", "children": [...]} | {"type": "file", "name", "path", "size", "mimetype", "timemodified" (ISO), "fileurl"} | {"type": "url", "name", "url"} ]}]}], "timestamp"}`. Field names may vary slightly but must be documented in MOODLE.md and be a nested structure.
   - NEVER append the token to `fileurl` or any URL in the output (downloading is F5, not now). The token must never appear in stdout/stderr/JSON.

## Exit codes (INTERFACE.md §3)
No stored token → 2. Server says `invalidtoken` → 3 (do not auto-relogin; delete nothing else). Connection error / HTTP ≥ 500 → 4. Unexpected response (HTML instead of JSON, missing fields) → 5. Not found/ambiguous course → 1. Other unexpected exceptions → 5 is acceptable as long as no traceback/secret is printed.
